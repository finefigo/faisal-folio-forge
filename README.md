# Faisal Imtiaz — Portfolio

Personal portfolio for Faisal Imtiaz, a final-year Computer Science and Engineering student interested in full-stack development and applied AI/ML.

## Run locally

Install dependencies with npm, then start the Vite development server:

    npm install
    npm run dev

## Built with

- React and TypeScript
- Vite
- Tailwind CSS
- Framer Motion

The portfolio presents selected projects, technical skills, research publications, education, certifications, awards, and contact links.
